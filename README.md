# 课时工资记录

记录每天上课情况、出勤学员、上课照片，并**按出勤人头自动计算工资**。纯前端网页，数据全部保存在本机浏览器，离线可用，登录后可编辑、否则只读预览。

## 工资规则（可在「设置」里改）

| 课程 | 计费方式 | 默认单价 |
| --- | --- | --- |
| C++ | 按出勤人头 | 30 元 / 人 |
| Python | 按出勤人头 | 25 元 / 人 |
| 入校 | 按次（手填学校支付金额） | 提示 ≥ 100 元 |

## 功能

- **记录**：选日期、课程类型，勾选出勤学员，上传上课照片（自动压缩），实时显示本节应得工资。
- **学员库**：维护学员名单，记录出勤时直接勾选；记录里也能临时添加。
- **工资统计**：按月查看 C++ / Python / 入校 的节数、人次与金额，含合计和累计。
- **照片**：每节课可存多张照片，点击查看大图。
- **编辑锁**：设置密码后，打开默认是「预览」模式，需登录才能修改（防止误改）。
- **备份**：一键导出含照片的备份文件，换设备时导入即可。

## 怎么用

### 方式一：直接打开（最简单）
双击 `index.html` 用浏览器打开即可使用。适合在电脑上记录。

> 注意：用 `file://` 直接打开时，浏览器「无痕/隐私模式」可能不保存数据；照片较多时建议用方式二。

### 方式二：放到手机上用（推荐，因为要上课拍照）
把这个文件夹发布到 **GitHub Pages**，手机浏览器打开网址即可，还能「添加到主屏幕」当 App 用：

1. 把本文件夹推送到一个 GitHub 仓库。
2. 仓库 **Settings → Pages → Build and deployment**，Source 选 `Deploy from a branch`，分支选 `main`、目录 `/ (root)`，保存。
3. 等一两分钟，访问 `https://<你的用户名>.github.io/<仓库名>/`。
4. 手机 Safari/Chrome 打开该网址 →「添加到主屏幕」。

也可以用任意静态服务器本地预览，例如在本文件夹下运行：

```bash
python3 -m http.server 8000
# 然后浏览器打开 http://localhost:8000
```

## 重要提示

- **数据存在本机**：每台设备、每个浏览器的数据是独立的，不会自动同步。换手机、清理浏览器数据前，请先在「设置 → 导出备份」。
- **编辑锁不是加密**：本地密码用于区分预览/编辑、防止误改，不能阻止技术手段查看本机数据。
- **想要多端同步 / 把考勤照片分享给机构核对？** 可以后续升级到「云端账号版」（账号登录、自动同步、可分享预览链接）。当前为本地版。
