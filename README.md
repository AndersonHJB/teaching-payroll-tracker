# 课时工资记录

记录每天上课情况、出勤学员、上课照片，并**按出勤人头自动计算工资**。

本版本（v2）数据保存在本机运行的 **Python 服务 + SQLite 文件（`data.db`）** —— 是真正的本地数据库文件，清浏览器缓存不会丢，可用任意 SQLite 工具打开、复制即备份。

> 仅用 Python 标准库，**无需 `pip install` 任何依赖**。

## 工资规则（可在「设置」里改）

| 课程 | 计费方式 | 默认单价 |
| --- | --- | --- |
| C++ | 按出勤人头 | 30 元 / 人 |
| Python | 按出勤人头 | 25 元 / 人 |
| 入校 | 按次（手填学校支付金额） | 提示 ≥ 100 元 |

## 启动

需要本机已安装 Python 3（macOS 自带）。

**方式一：双击（macOS）**
双击项目里的 `start.command`。首次可能被系统拦截，在「访达」里右键该文件 →「打开」即可。

**方式二：命令行**
```bash
cd 本项目文件夹
python3 server.py            # 默认 http://localhost:8000
python3 server.py 8080       # 指定端口
```

启动后会自动打开浏览器（任意浏览器均可）。停止：在终端按 `Ctrl+C`。

## 功能

- **记录**：选日期、课程类型，勾选出勤学员，上传上课照片（自动压缩），实时显示本节应得工资。
- **学员库**：维护学员名单，记录出勤时直接勾选；记录里也能临时添加。
- **工资统计**：按月查看 C++ / Python / 入校 的节数、人次与金额，含合计和累计。
- **照片**：每节课可存多张照片（存进 SQLite），点击查看大图。
- **编辑锁**：设置密码后，打开默认是「预览」模式，需登录才能修改（防止误改）。密码用 PBKDF2 加盐存于服务端。
- **备份**：直接复制 `data.db` 即可；也可在「设置」里一键下载数据库文件。

## 数据与备份

- 所有数据（含照片）都在项目目录下的 **`data.db`**。想备份就复制这个文件；想换电脑，把它拷过去放到同目录即可。
- `data.db` 已被 `.gitignore` 排除，不会被提交到仓库。
- 用 [DB Browser for SQLite](https://sqlitebrowser.org/) 等工具可直接打开查看。

## 使用范围（本地版的取舍）

- 需要先启动本地服务才能用；**仅这台电脑可访问，手机不能直接打开**（手机/多设备需要云端版）。
- 这是为了"数据是真实本地文件、不依赖浏览器、清缓存不丢"所做的取舍。

## 文件说明

| 文件 | 作用 |
| --- | --- |
| `server.py` | 本地服务端（标准库 + SQLite），提供 API 并托管页面 |
| `start.command` | macOS 双击启动脚本 |
| `index.html` / `styles.css` / `app.js` | 前端页面与逻辑 |
| `manifest.webmanifest` / `icon.svg` | 图标与站点信息 |
| `data.db` | 你的数据库（运行后生成，不入库） |
